# Saniya Portfolio Website

Responsive portfolio project built with HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — visual design and responsive layouts
- `script.js` — mobile navigation, project carousel controls, and current year

## Run it
Open `index.html` in a browser. VS Code Live Server is convenient but not required.

## Before publishing
1. Confirm the display name and update it if needed.
2. Replace `hello@example.com` in `index.html` with your real contact email.
3. Check that the Funngro link and every project description accurately reflect work completed.
4. Test navigation and carousel on desktop and mobile.
5. Publish this portfolio in a separate GitHub repository; do not overwrite your earlier project.
